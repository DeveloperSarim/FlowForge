# Security policy

## Supported versions

Security fixes go into the latest release. Update from Settings → Updates to stay current.

## Reporting a vulnerability

Please **don't** open a public issue. Email **[support@sarimtools.com](mailto:support@sarimtools.com?subject=FlowForge%20security)** with:
- what the problem is and where (file, route or screen),
- the steps to reproduce it,
- the FlowForge version you tested.

You'll get a reply within 3 business days. We'll keep you updated while we fix it and credit you in the release notes if you'd like.
