FlowForge: self-hosted workflow automation for PHP hosting

FlowForge is a visual workflow automation platform, in the same family as n8n, Make and Zapier, that runs on ordinary shared hosting. Connect 1,190 apps on a drag-and-drop canvas, or describe a workflow in plain words and let the AI Builder make it. Everything runs on your own server with one cron job: no Docker, Node.js, Redis or monthly per-task fees.

Live demo | Documentation | Free installation: support@sarimtools.com

Why FlowForge

  • Runs where your website runs. Hostinger, cPanel, DirectAdmin or any VPS with PHP 8.2+ and MySQL. Upload, run the setup wizard, done.
  • No per-task pricing. Run as many workflows and tasks as your server handles.
  • Your data stays on your server. Credentials are encrypted and never sent to the browser.

Features

  • Visual workflow builder with triggers, actions, If/Else branches and filters
  • 1,190 apps with 5,783 actions and 615 triggers: Gmail, Slack, Google Sheets, HubSpot, Shopify, WooCommerce, Stripe, OpenAI, LinkedIn, Telegram, Notion, Airtable and more
  • HTTP request step and "Make an API call" for any API
  • AI Builder: describe a workflow and it builds it, with DeepSeek, Qwen, OpenAI, Anthropic Claude or Google Gemini (your own key)
  • Webhook, schedule, app (polling), manual and error triggers
  • Friendly schedule picker: "every weekday at 9:00", no cron syntax
  • Step editor with drag-and-drop data mapping between steps
  • Execution history with each step's input, output and HTTP request, plus retry
  • 50 ready-made templates
  • Team members with roles and per-module permissions (view, edit, delete, AI)
  • Email alerts when a workflow fails or the scheduler stops
  • MCP server: Claude Code, Cursor and VS Code agents can build and run workflows
  • One-click updates from Settings, with automatic backup and rollback
  • Setup wizard that checks your server and verifies the cron job
  • Works on phones like a native app; light and dark themes
  • Password reset by email code, timezone setting, SEO-ready sign-in page

Requirements

  • PHP 8.2 or newer with pdo_mysql, curl, mbstring, openssl, fileinfo, gd, zip
  • MySQL 5.7+ or MariaDB 10.3+
  • Apache/LiteSpeed (mod_rewrite) or Nginx
  • One cron job every minute (every hPanel and cPanel plan allows it)
